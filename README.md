## Context Kit

I’m currently building [Context Kit](https://github.com/fayedintoyou/context-kit), a Git-backed way to give agents durable context and working methods across projects.

The basic idea is that useful context should be inspectable, reviewable, and able to evolve alongside the work. Rather than treating context as a giant prompt or an opaque retrieval layer, Context Kit organizes it into small, navigable hubs that agents can progressively browse and read as needed. The same system can carry working methods, skills, specifications, provenance, trust, and freshness signals without turning them into hidden state.

It’s also where I’m experimenting with a broader question I keep coming back to: **what should we make deterministic, and what should we leave to the model?**
